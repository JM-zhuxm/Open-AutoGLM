## 一、我想做什么?

我的终极目标是:**让手机成为机器人"大脑和神经中枢"**。

```
具体来说:
  - 机器人 = 身体(标准化、可替换)
  - 手机 = 大脑 + 神经中枢(可升级、可替换)

  → 手机越新、越强,机器人越聪明、越能干活
```

举个例子:你们看我桌上摆的那个小机器人(V1),以前它的"脑子"其实是一个叫 CoreS3SE 的小芯片,只能听懂"芝麻开门"这种简单指令。但**当我把我的 OPPO A58 手机接上去之后,它立刻变得能说会道、能听能想、能联网查资料,甚至能主动跟我聊天**。

这就是我想做的事——**让任何机器人,只要插上一部手机,就立刻拥有大脑**。
