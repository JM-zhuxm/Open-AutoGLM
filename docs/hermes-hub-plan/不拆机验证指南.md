### 步骤 3️⃣:**A58 连接 ADB**(我执行)

```bash

# 2. 扫端口找 A58(JM 告知端口号,默认试 5555/45731/35185)

  adb connect 100.110.37.65:$port 2>&1
done

adb devices -l
```

### 步骤 4️⃣:**推送 + 安装 V3.1.2 APK**(我执行,5 分钟)

```bash
# 1. Push 到手机 /data/local/tmp/
adb -s 100.110.37.65:xxxx push \
  /home/ubuntu/phonebot-r1/dist/phonebot-r1.apk \
  /data/local/tmp/app.apk

# 2. 用 pm install 本地装(避免 -99 静默超时)
adb -s 100.110.37.65:xxxx shell pm install -r -t /data/local/tmp/app.apk

# 3. 启动 App
adb -s 100.110.37.65:xxxx shell am start -n com.phonebot.r1/.MainActivity
```
