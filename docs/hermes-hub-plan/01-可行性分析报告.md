### 核心洞察

> **一台足够强大的手机 = 大脑和神经中枢**,给予桌面机器人 + 具身机器人最主要的链接。手机除了打电话,还是 AI 设备的中枢。**手机可更换,手机越高级,设备越厉害**。

## 1. 项目概述

### 1.1 愿景

```
手机 = 大脑 + 神经中枢(可升级)
机器人 = 身体(标准化)

手机换一台 Find X8 → 所有机器人立刻变聪明
```

### 1.2 三大产品阶段

| 阶段 | 时间 | 内容 |
|---|---|---|
| Phase 1 | 已完成 90% | PhoneBot-R1 灵魂拼装(V1-V4 形态) |
| Phase 2 | 3-6 月 | Hermes HUB SDK v1.0(开源 + AutoGLM 集成) |
| Phase 3 | 6-12 月 | Hermes HUB 生态(标准机器人 + 手机厂商合作) |

### 1.3 核心创新点

1. **手机-机器人解耦**:手机不再只为机器人提供算力,而是机器人的大脑
2. **升级曲线**:用户换手机,所有机器人立刻升级(无需重新购买)
3. **多机协同**:1 台手机驱动 N 个机器人(标准化身体)
4. **生态标准**:JM 的 SDK 成为"AI 机器人控制"的事实标准
