# Hermes HUB — 商业开发文档

## 1. 商业愿景

### 1.1 核心定位

**Hermes HUB = 重新定义"AI 机器人"的产品类别**

不是"能 AI 的机器人",而是"以手机为大脑的机器人系统"。

### 1.2 价值主张

```
对消费者:
  ¥100 机器人 + 现有手机 = 强大 AI 机器人
  换手机 → 所有机器人升级

对开发者:
  一次开发,跨多手机厂商兼容
  Skill 商店变现

对企业:
  AI 工人成本 < 人类工人 50%
  跨设备标准化采购
```

### 1.3 愿景陈述

> **5 年内,成为 AI 机器人控制的事实标准,让手机成为机器人天然的大脑。**

## 10. 风险与应对

### 10.1 主要风险

| 风险 | 概率 | 影响 | 应对 |
|---|---|---|---|
| 大厂自研 | 中 | 高 | 抢先开源 + 社区粘性 |
| USB 兼容性 | 中 | 中 | 多协议支持 |
| 极客不付费 | 高 | 中 | B2B 商业化 |
| 法规限制 | 低 | 中 | 合规先行 |
| 团队流失 | 中 | 高 | 文档化 + 社区 |

### 10.2 应对措施

1. **开源优先**:即使被模仿,标准也是 JM 的
2. **多平台**:Android / iOS / HarmonyOS 全支持
3. **B2B 优先**:比 B2C 更稳
4. **持续创新**:Skill Marketplace 持续扩展

## 13. 关键决策点

### 13.1 技术决策

| 决策点 | 推荐 | 理由 |
|---|---|---|
| 协议类型 | USB CDC | 标准化 + 简单 |
| 通信框架 | 自研 JSON 协议 | 灵活可控 |
| LLM 部署 | 云端 + 本地混合 | 兼容不同手机 |
| Skill 框架 | 自研 | 简单灵活 |

### 13.2 商业决策

| 决策点 | 推荐 | 理由 |
|---|---|---|
| 开源协议 | Apache 2.0 | 商业友好 |
| 商业模式 | SDK + 硬件 + B2B | 多条路径 |
| 首批客户 | 极客 + 高校 | 验证 + 传播 |
| 营销策略 | 内容 + 社区 | 低成本高质量 |
